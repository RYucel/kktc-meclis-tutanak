# KKTC Cumhuriyet Meclisi Tutanak Arama (1960–2026)

[`stevevaius/KKTC_Meclis_Tutanak`](https://huggingface.co/datasets/stevevaius/KKTC_Meclis_Tutanak) veri seti üzerinde çalışan **konuşmacı bazlı** ve **tam metin** arama uygulaması.

* **1.272.408** konuşma bloğu · **3.694** oturumlu tutanak belgesi · **9.499** konuşmacı
* Kapsam: Kıbrıs Cumhuriyeti (1960), Türk Cemaat Meclisi (1963), KTY, KTFD, Kurucu Meclisler ve KKTC Cumhuriyet Meclisi Dönem 1–10
* Özellikler: Konuşmacı profili, yıllık konuşma zaman çizelgesi, oturum içi bağlam okuyucu (önceki/sonraki sözler), kaynak belge bağlantısı ve CSV dışa aktarımı.
